Teoría · Repaso del Set 1

🛰️ Internet y servidores web

Una página web es un documento escrito en HTML que está guardado en un ordenador llamado servidor. Cuando la pides, viaja por Internet hasta tu navegador, que la «dibuja» en pantalla.

📄

Página web

Es un documento escrito en HTML que puede tener texto, imágenes, vídeos y enlaces a otras páginas. Se ve con un navegador.
📚

Sitio web

Es un conjunto de páginas web enlazadas entre sí, con un mismo dominio. Por ejemplo, la web de tu instituto tiene muchas páginas.
🖥️

Servidor web

Es un ordenador (y el programa que lleva dentro) que guarda páginas web y las envía a quien las pide. Está encendido las 24 horas y conectado a Internet.
🧰

¿Para qué se usan?

Para alojar webs, tiendas online, blogs, plataformas como Moodle o Classroom, guardar archivos en la nube, servir vídeos y juegos online…

¿Qué pasa cuando escribes una dirección?

Pulsa el botón y fíjate en los pasos:

⌨️1. Escribes la URL
en el navegador
📒2. DNS
traduce el nombre a una dirección IP (como una agenda de teléfonos)
📨3. Petición HTTP
tu navegador le pide la página al servidor
🖥️4. El servidor responde
y envía el archivo HTML, las imágenes…
🎨5. El navegador dibuja
la página que ves

¿Qué es una dirección IP?

Cada aparato conectado a Internet (tu móvil, este ordenador, el servidor de YouTube…) tiene un número que lo identifica: su dirección IP (IP viene de Internet Protocol). Gracias a ese número, la información sabe a qué aparato tiene que llegar.

🏠

Como la dirección de tu casa

Para que te llegue un paquete hace falta tu dirección. En Internet pasa lo mismo: sin IP, los datos no saben adónde ir.
🔢

Cómo es (IPv4)

Son 4 números del 0 al 255 separados por puntos.
192.168.1.25
Hay unos 4.300 millones de combinaciones… ¡y ya no llegan para todos los aparatos del mundo!
🧬

La versión nueva (IPv6)

Es mucho más larga, con letras y números:
2001:db8:85a3::8a2e:370:7334
Da direcciones para billones de aparatos.
🌍

Pública y privada

La IP pública es la que te ve Internet (la de tu router o la del instituto). La IP privada es la que tiene cada aparato dentro de tu casa o de tu clase, y suele empezar por 192.168…

📒 El DNS: la agenda de contactos de Internet

A las personas se nos dan mal los números, así que usamos nombres (dominios). El DNS traduce el nombre a la IP, igual que la agenda de tu móvil traduce «Mamá» en un número de teléfono. Elige una web:

➡️ ¿IP?

* Son IP de ejemplo: las webs grandes tienen muchos servidores y su IP cambia según desde dónde te conectes.

🕵️ Curiosidad y seguridad: cada web que visitas ve tu IP pública y, con ella, sabe más o menos desde qué ciudad te conectas. Por eso se dice que en Internet nunca eres totalmente anónimo.

Las partes de una URL

Una URL (Uniform Resource Locator, localizador uniforme de recursos) es la dirección exacta de una página, imagen o archivo en Internet. Haz clic en cada color:

https://www.ejemplo.es/clase/3eso/index.html?tema=html#inicio
👆 Elige una parte de la URL.

Tipos de servidores web

No todas las webs se guardan igual. Depende de cuántas visitas tengan y del dinero que quieran gastar:

🏢

Compartido

Muchas webs pequeñas viven en el mismo ordenador y se reparten sus recursos. Es barato o incluso gratis. Ejemplo: un blog personal.
🧩

VPS (servidor privado virtual)

Un servidor físico se divide en varios «servidores virtuales». Cada uno tiene su parte reservada.
🏰

Dedicado

Un ordenador entero solo para tu web. Es potente, pero caro. Ejemplo: una tienda online grande.
☁️

En la nube

Muchos servidores trabajan juntos y crecen si hay más visitas. Ejemplo: Netflix o YouTube.
🏠

Local

Tu propio ordenador. Solo tú ves la página. Así vamos a trabajar en clase.

Más palabras clave

HTTP / HTTPS
Es el «idioma» que usan el navegador y el servidor para hablar. La S significa «seguro»: los datos viajan cifrados 🔒.
Cookies 🍪
Pequeños archivos que una web guarda en tu navegador para recordarte: tu sesión, tu idioma, lo que hay en tu carrito… ¡y también para saber qué te interesa!
Otros protocolos
FTP (subir archivos), SMTP (enviar correos), DNS (traducir nombres a direcciones IP)…

Teoría · Set 2

🧠 Lenguajes y herramientas web

Piensa en una web como en un cuerpo humano: HTML es el esqueleto, CSS es la ropa y el aspecto, y JavaScript son los músculos que la hacen moverse.

🦴

HTML

Estructura. Dice qué es cada cosa: esto es un título, esto es un párrafo, esto es una imagen.
👕

CSS

Aspecto. Colores, tipos de letra, tamaños, posiciones y animaciones. (Lo veremos en el 2.º trimestre).
💪

JavaScript

Comportamiento. Botones que reaccionan, juegos, relojes, formularios… (2.º trimestre).
✨

HTML5

La versión actual de HTML. Añade vídeo, audio y etiquetas como <header> o <footer>.
📦

XML

No sirve para dibujar páginas, sino para guardar y compartir datos de forma ordenada.
📏

XHTML

Un HTML «estricto», con reglas de XML. Si te dejas una etiqueta sin cerrar, falla.
🪦

Flash

Servía para animaciones y juegos web. Dejó de funcionar en 2020 por problemas de seguridad. Lo sustituyeron HTML5, CSS y JavaScript.

Herramientas del desarrollador web

📝

🖱️

Editores visuales (WYSIWYG)

«Lo que ves es lo que obtienes»: Google Sites, Wix, WordPress. Arrastras y sueltas.
🌐

Navegadores

Firefox, Chrome, Edge. Muestran la web y traen herramientas de desarrollador (pulsa F12).
⚡

Editores online

CodePen, JSFiddle. Programas en el navegador y ves el resultado al momento.
🖼️

Diseño gráfico

Canva, GIMP, Inkscape. Para logos, botones e imágenes.
📤

Subir archivos (FTP)

FileZilla. Sirve para subir tu web al servidor.

Código · Set 3

🦴 El esqueleto de toda página HTML

HTML funciona con etiquetas: palabras entre < >. Casi todas van en pareja: una abre y otra cierra (la que cierra lleva una barra /).

Este es el esqueleto que tendrán todas tus páginas. Cópialo en VS Code:

¿Qué significa cada línea?

CódigoPara qué sirve
<!DOCTYPE html>Avisa al navegador: «esto es HTML5». Va siempre en la primera línea.
<html lang="es">Es la caja que contiene todo. lang="es" indica que la página está en español.
<head>La parte «invisible»: información sobre la página que no se ve dentro de ella.
<meta charset="utf-8">Hace que se vean bien las tildes y la ñ. ¡Sin esto verás «EspaÃ±a»!
<title>El texto que aparece en la pestaña del navegador.
<body>El cuerpo: todo lo que se ve en la página va aquí dentro.
<!-- ... -->Un comentario: una nota para ti que el navegador ignora.
🪆 Regla de las muñecas rusas: las etiquetas se cierran en orden inverso al que se abren. Si abres <b><i>, cierras </i></b>.
↹ Sangría: mete hacia dentro (con Tab) lo que está dentro de otra etiqueta. Así verás de un vistazo qué contiene cada cosa.
Código · Retos 4-6

🎨 Dar formato al texto

Recuerda: estas etiquetas van dentro de <body>. Pulsa 🧪 Probar para verlas funcionar en el laboratorio.

Títulos: de <h1> a <h6>

h1 es el título más grande e importante y h6 el más pequeño. Usa un solo <h1> por página, como el título de un libro.

Párrafos y saltos de línea

HTML ignora los Enter que pulsas en el código. Para separar bloques de texto usa <p>, y para bajar de línea dentro de un párrafo, <br> (esta etiqueta no se cierra).

Negrita, cursiva, subrayado…

💡 Hoy en día se prefieren <strong> (importante) y <em> (énfasis) en lugar de <b> e <i>. Se ven igual, pero tienen más significado, por ejemplo para los lectores de pantalla que usan las personas ciegas.

Color, tamaño, letra y alineación con style

El atributo style cambia el aspecto de cualquier etiqueta. Se escribe propiedad: valor; y puedes poner varias propiedades separadas por punto y coma.

PropiedadQué cambiaEjemplos de valor
colorColor del textored, navy, #ff6600
background-colorColor de fondolightyellow, #e0f2fe
font-sizeTamaño de la letra14px, 30px
font-familyTipo de letraArial, Georgia, 'Comic Sans MS', monospace
text-alignAlineaciónleft, center, right, justify
🕰️ ¿Y la etiqueta <font> o bgcolor? En webs antiguas verás <font color="red"> o <body bgcolor="yellow">. Están obsoletas: aún funcionan, pero ya no se usan. Nosotros lo hacemos con style, que es el primer paso hacia CSS.

Código · Retos 4-6

🔗 Listas, líneas, enlaces, imágenes y tablas

Listas

<ul> crea una lista con puntos, <ol> una lista numerada y <li> es cada elemento. <dl> es una lista de definiciones, como un diccionario.

Línea horizontal

Enlaces (hipervínculos)

La a viene de anchor («ancla»). En href va la dirección. Con target="_blank" el enlace se abre en una pestaña nueva.

Imágenes

Guarda la imagen en la misma carpeta que tu archivo .html y escribe su nombre exacto en src. En alt va una descripción de la imagen (para quien no puede verla). Con width cambias su anchura.

©️ ¡Ojo con los derechos de autor! No todas las imágenes de Internet se pueden usar libremente. Busca imágenes con licencia libre (por ejemplo, en Pixabay, Unsplash o Wikimedia Commons), usa tus propias fotos o tus diseños de Canva. Si la licencia lo pide, indica quién es el autor.

Tablas

<table> es la tabla, <tr> cada fila (table row), <th> una celda de encabezado y <td> una celda normal (table data).

📐 Truco: dibuja primero la tabla en papel y cuenta sus filas. Cada fila es un <tr> y cada casilla de esa fila, un <td>.
